Chrome Extension • Encar • GA4

차량 가격 추적을
브라우저 안으로.

`car-price`는 엔카 LIST/DETAIL 페이지에서 차량 가격을 추출하고, 가격 이력을 `chrome.storage.local`에 저장한 뒤, 화면 위에서 바로 가격 변동과 추적 상태를 보여주는 확장 프로젝트입니다.

핵심 구조

Local-Only 저장

운영 저장소는 `chrome.storage.local`입니다. Firebase는 제거됐고, 저장/조회/상태 계산은 전부 로컬 기준으로 동작합니다.

분석 계층 분리

GA4는 분석 이벤트 전송 전용 계층입니다. 저장 흐름을 막지 않도록 fire-and-forget 방식으로 연결되어 있습니다.

LIST / DETAIL 추적

LIST 카드 노출, DETAIL 진입, 가격 관측, 가격 변경, 상태 변경 이벤트를 분리해서 측정할 수 있습니다.

문서

GA4 Debug Checklist

DebugView 검증 순서, 이벤트 확인 방법, 수동 점검 절차를 정리한 문서입니다.

GA Migration

Firebase 기반 구조에서 GA4 기반 분석 계층으로 이동한 방향과 설계 판단을 정리했습니다.
